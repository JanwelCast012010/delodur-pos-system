# Keyboard Barcode Scanner Guide

## 🎯 Perfect for Physical Barcode Scanners!

Your inventory system now fully supports **keyboard wedge barcode scanners** - the most efficient way to scan barcodes in a warehouse environment.

## 🚀 How It Works

### Automatic Detection
- **No setup required** - just plug in your USB barcode scanner
- The system automatically detects keyboard input from your scanner
- Works with any keyboard wedge scanner (USB, Bluetooth, etc.)

### Real-time Scanning
- **Instant processing** - scan and the item is immediately added
- **Visual feedback** - see "Scanning..." status when input is detected
- **Auto-clear** - input clears automatically after processing

## 📱 Using Your Keyboard Scanner

### 1. Inventory Audit
1. Navigate to **Inventory Management > Inventory Audit**
2. Click **"Start New Audit"**
3. **Simply scan any barcode** - no clicking needed!
4. The system will:
   - Find the product in your database
   - Show current system quantity
   - Add to your audit list
   - Calculate discrepancies automatically

### 2. Bulk Scanner
1. Navigate to **Inventory Management > Bulk Scanner**
2. Enter a session name and select mode:
   - **Add Mode**: Increment quantities (for receiving stock)
   - **Remove Mode**: Decrement quantities (for sales/shipping)
   - **Count Mode**: Set exact quantities (for counting)
3. Click **"Start New Session"**
4. **Simply scan barcodes** - they'll be added instantly!

## 💡 Tips for Best Results

### Scanner Setup
1. **Ensure scanner is in keyboard wedge mode**
2. **Test scanner in any text field first**
3. **Make sure scanner adds Enter at the end**

### Scanning Tips
1. **Good lighting** - ensures accurate scanning
2. **Clean barcodes** - damaged barcodes may not scan
3. **Proper distance** - follow scanner manufacturer guidelines
4. **Steady hands** - reduces scanning errors

### Troubleshooting
- **Scanner not working?** Check if it's in keyboard wedge mode
- **Items not found?** Verify barcode exists in your products database
- **Slow response?** Check your internet connection
